## 高频考点与标准答法

### 1. 定义题要"给公式 + 讲边界"（Q1/Q35）
- 公式：`Agent = LLM（大脑）+ 规划 + 记忆 + 工具 + 反馈闭环`
- 必须点出与 Chatbot 的分界：**自主拆解目标 + 调用工具改变外部状态 + 观察结果后修正**（→ [[01-Wiki/concepts/AI Agent]]、[[01-Wiki/concepts/Workflow Graph]]）

### 2. 范式题要"讲清为什么有效"（Q2/Q3）
- [[01-Wiki/concepts/ReAct]] 的杀伤力不在循环本身，而在 **Action 把推理锚定到外部真实信息**，这是它优于纯 CoT 的根因；代价是**误差级联 + 成本 + 死循环**
- 规划方法按"搜索空间 / 是否回溯"递进：CoT → Self-Consistency → ToT → GoT；生产上是**难度路由 + 组合使用**，不做全局单一选择

### 3. 记忆题是最高频的深水区（Q4/Q20/Q21/Q41）
- 面试官真正想听的不是"用向量库"，而是**写什么 / 读什么 / 何时忘**三问（→ [[01-Wiki/concepts/Agent 记忆系统]]）
- 海量历史优化三板斧：**减数据（摘要/淘汰）+ 缩空间（分片/过滤）+ 快索引（ANN/rerank）**

### 4. 工具调用分"协议层 vs 训练层"（Q5/Q39/Q43/Q50/Q52）
- Function Calling 是**推理时的接口协议**；Toolformer 是**训练时把工具内化进权重**（→ [[01-Wiki/concepts/Tool Calling]]）
- 参数格式稳定要三手齐下：**schema 约束 + 约束解码 + 容错解析/校验重试**
- "调用不正确怎么办"的标准路径：**先诊断现象（选错/参数错/该调不调）→ prompt 与工具设计优先 → SFT 打格式基础 → RL 提成功率**；多数问题不该动权重

### 5. 多智能体保持"克制"立场（Q9/Q18/Q19/Q32/Q34/Q36）
- 优势（专业化/上下文解耦/多视角校验）必须与代价（误差级联/协调成本/token/信用分配难）对举
- 提正确率靠：**角色分工 + 交叉验证 + 多路径投票 + 反思重试 + 专家路由**
- 工程关键是**收敛机制**：最大轮次、预算上限、相同错误去重、收益递减即停（→ [[01-Wiki/concepts/单 Agent 与多 Agent]]）

### 6. 安全题答"不信任模型"（Q13/Q46）
- 核心立场：**安全不能交给 LLM 自己保证，要落在系统层**——纵深防御 + 最小权限 + 人在回路（→ [[01-Wiki/concepts/Agent 安全与对齐]]）
- 三件底线投资：**能拦住（guardrail/ACL）、能看见（全链路 trace/审计）、能撤销（幂等/补偿/回滚）**

### 7. 工程题答"分层 + 量化"（Q16/Q17/Q24/Q27/Q30/Q31）
- 资源调度五件套：**异步解耦 + 队列 + 自动扩缩 + 批处理 + 隔离**
- GPU 推理 vs 微调：**推理保时延（高优不可中断）、微调保吞吐（低优可抢占）**
- 时延与精度不做二选一，用**级联架构（快路径 + 难例升级）**
- LangChain memory 并发隔离的三板斧：**会话级 namespace + 外部持久化 + 无状态服务**
- 一致性的工程现实答案：**会话级串行化 + 乐观锁/幂等 + 最终一致 + 补偿事务**，而非分布式强一致

### 8. 评估题答"分层指标 + 归因"（Q33/Q37/Q48）
- 三层指标：**结果层（任务成功率）→ 过程层（工具准确率/步数/幻觉率）→ 系统层（P95/token 成本）**
- 鲁棒性不止准确率：**注入/越狱、输入扰动、工具异常、环境异常、超界任务**，看"扰动下的成功率下降幅度"与**是否优雅降级（fail safe）**
- 多步任务评测的真难点是**归因**——必须每步留 trace 做分步评分

## 亮点与不足

**亮点**
- **真题标注明晰**：每题带难度星级、岗位倾向（算法岗/开发岗）、标签、公司来源，可直接当复习优先级表用
- **覆盖面完整**：从"什么是 Agent"到"GPU 资源分配"，恰好是 Agent 岗从理论到生产的全链路
- **第七部分真实度高**：资源调度、并发隔离、容错降级这类题只有做过生产系统才答得出，是区分度所在

**不足**
- ⚠️ **源文件命名与内容不符**：文件名与 frontmatter `title` 为 `02-rag-questions.md`，实际正文是 **Agent 核心篇**（frontmatter `source` 指向 `03-agent-questions.md`），是剪藏器的串号问题
- ⚠️ **原文无任何答案**：全部 52 题仅有题面，需自行补答（本次已在源文件内逐题补参考答案）
- **答法偏"标准答案"**：题目本身不提供项目背景，同一题的答案在不同场景下差异极大（尤其 Q6/Q23/Q42 这类"你有没有做过"的经历题）
- **纯文本无公式/图表**：ReAct、ToT/GoT、A2A 等本可用图示更清晰
