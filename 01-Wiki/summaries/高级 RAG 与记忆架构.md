# 高级 RAG 与记忆架构（zero2Agent 基础 16）

> 从基础向量检索到 GraphRAG、Contextual Retrieval 和双层记忆系统——当基础向量检索无法满足 Agent 知识需求时的进阶方案。

## 基础 RAG 的四大瓶颈

| 瓶颈 | 表现 | 根因 |
|------|------|------|
| Chunk 孤立 | 检索段落脱离上下文，模型无法理解位置 | 切分丢弃文档级结构 |
| 语义鸿沟 | 问"怎么扩容"文档写"水平伸缩"，余弦相似度低 | Query 与 Document 用词体系不同 |
| 扁平检索 | "A 与 B 什么关系"需先找 A 再找 B 再推理 | 单次检索无法多跳推理 |
| 结果噪声 | Top-K 混入语义相关但对当前问题无用的段落 | 相关性 ≠ 有用性 |

## Contextual Retrieval：上下文增强检索（成本最低）

索引阶段用 LLM 为每个 chunk 补一段 50-100 字"上下文前缀"描述其在原文中的位置作用，检索时前缀参与 embedding 计算。召回率提升 20-50%（Anthropic 实验数据）；成本集中在离线索引阶段，在线无额外开销；适合文档更新频率中低。

## GraphRAG：基于图结构的检索

文档实体与关系建模为知识图谱，检索利用图连通性多跳推理。三步：实体抽取（LLM 识别命名实体）→ 关系构建（有向图）→ 图遍历检索（定位起始实体沿边遍历 1-3 跳收集子图）。适用：多实体关联查询、全局聚合问题（"最核心的 5 个模块"）、组织知识管理/合规审查。局限：构建成本高、图质量依赖抽取准确性（错误关系→错误推理路径）、实时性差。→ 详见既有概念 [[01-Wiki/concepts/GraphRAG]]。

## RAPTOR：递归摘要树

chunk 按语义聚类→每簇生成摘要→摘要再聚类再生成上层摘要→递归成树。三种检索策略：自底向上（叶子匹配置信度不够上升父层）、自顶向下（先定主题再下钻）、全层级搜索（统一入库让相似度自然决定层级）。适用：长文档理解（技术规范/法律合同/论文）、兼顾全局视野与细节准确、查询粒度不确定。

## 双层记忆架构

设计动机：Agent 需"认识"用户/掌握长期知识，但不能每次把全部记忆塞进 Context。**低成本保持全局感知 + 按需检索补充细节**。

- **第一层：概览卡片**（结构化 JSON，<2000 tokens，始终放 System Prompt/Context 前部）：user_profile（name/role/tech_stack/preferences/active_projects）+ last_updated。每次会话结束更新。
- **第二层：详细记忆**（工具按需检索）：`@tool recall_memory(query, time_range)` 向量库 top_k 检索。实时写入。

工程要点：第一层固定 token 开销 <2K、第二层按检索量动态增长；信息粒度第一层摘要标签关键事实、第二层原始记录完整上下文。

## 记忆评估框架（分层）

- **Level 1 基本召回**：能否找到明确存储过的事实（不同措辞查询）。基线 >95% 准确召回。
- **Level 2 多轮关联**：能否跨会话关联分散信息（"我在做 X"+"X 依赖 Y"→问"我的项目依赖什么"）。基线推理正确率 >80%。
- **Level 3 主动服务**：能否主动关联历史偏好提供个性化帮助而非被动应答。基线"有帮助"比例 >60%（人工评估）。

## 记忆的隐私与遗忘

- **GDPR 删除权**：embedding 能按 user_id 过滤删除、概览卡片缓存级联清除、删除后验证不再命中。
- **过期策略**：TTL 分级（user_preference 180 天、project_context 90 天降权、factual_statement 365 天重新确认）。
- **选择性遗忘**：用户纠正时标记原记忆"已失效"（保留审计链）→ 写入新记忆 → 更新概览摘要 → 确保后续检索不返旧版。
- **猜测不升级为事实**：模型推断不能自动写长期记忆——"用户提到正在学 Rust"（有明确来源）可写；"用户可能对系统编程感兴趣"（推断）只能作临时推理标签。只有用户明确确认或多次行为一致验证才能升级为长期事实。

## 选型决策路径

1. 确认基础 RAG 瓶颈属于哪类
2. Chunk 孤立 → Contextual Retrieval（成本最低）
3. 需多跳/全局聚合 → GraphRAG
4. 文档长且粒度不确定 → RAPTOR
5. Agent 需长期记忆 → 双层架构

记忆系统的工程挑战不仅在"记住"，更在于"遗忘得体面"和"记忆有分寸"。
