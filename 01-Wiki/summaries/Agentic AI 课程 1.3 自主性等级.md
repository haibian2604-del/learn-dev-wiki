# Agentic AI 课程 1.3 自主性等级

> 用"Agentic"作**形容词**而非名词，把"是不是真正的 Agent"之争换成"自主程度有多高"的连续光谱——低自主是硬编码流程，高自主是模型自己决定步骤、工具甚至新建工具。

## 核心观点

- **讨论现状**：过去几年 AI 社区对"什么是智能体"存在争议——有人写论文定义它，有人否认某些系统是"真正的智能体"
- **本课的解法**：用 `Agentic` 作形容词，允许说一个系统"具有某种程度的智能体特性"，而不是纠结它是否"足够自主"才能被叫智能体；**承认不同系统在主动性上的不同程度**，而非争谁算数（→ [[01-Wiki/concepts/Agentic AI 工作流]]）
- **这正是术语创造的动机**：已经有了 `agent` 这个名词，还需要 `Agentic` 这个形容词来做连续谱描述

## 光谱两端对比（写论文为例）

| 维度 | 低自主性 Less autonomous | 高自主性 More autonomous |
|------|------------------------|-------------------------|
| 步骤 | 全部预先设定 | 模型动态决定步骤顺序 |
| 工具调用 | 硬编码（hard-coded），工程师在代码里写死 | 模型自主选择工具（web search / news / arXiv / web fetch / pdf to text） |
| 模型职责 | 主要自主性只体现在"生成文本"上 | 还能创建新的、可执行的工具（函数）来完成任务 |
| 典型流程 | 告诉 LLM 写论文 → LLM 出关键词 → 人去搜 → 人抓内容 → LLM 整合成文 | LLM 自己决定先搜 → 自己判断选 5 个最佳来源 → 自己写初稿 → 自己反思"逻辑不够强、数据没引用清楚" → 自己改进 |
| 类比 | "听话但不会动脑"的助手，你得一步步指挥 | "聪明又有责任心的实习生"，全程自规划、自调用、自优化，交成品 |

## 一句话总结（原文）

> Agentic AI 的精髓不是"能干活"，而是**"会自己想怎么干、用什么工具、干完还能自己检查改错"**——这才是真正意义上的 agent，而不是"高级打字机"。

## 亮点与不足

- 亮点：用一个形容词化解了行业定义之争，且直接引出后面所有设计模式（反思=自己改错、工具=自己选工具、规划=自己想怎么干）
- 不足：只有"低/高"两端示意，未给出可操作的中间分级刻度与判定方法

## 与既有知识的联系

- 支持 [[01-Wiki/concepts/AI Agent]]：本课把"是否是 Agent"改成"有多 agentic"，与面试题里"单 Agent 优先"的务实取向一致（→ [[01-Wiki/concepts/单 Agent 与多 Agent]]）
