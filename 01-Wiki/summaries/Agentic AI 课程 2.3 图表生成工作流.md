# Agentic AI 课程 2.3 图表生成工作流

> 反思 + **多模态**的实战：让多模态模型"真正地看"自己生成的图表并给改进建议，把粗糙初稿迭代成专业可视化。

## 核心观点

案例：咖啡销售数据（coffee_sales.csv）画 Q1 2024 vs 2025 对比图。

**直接生成阶段**

1. 提示："Create a plot comparing Q1 coffee sales in 2024 and 2025 using coffee_sales.csv."
2. LLM 生成 V1 Python 代码 → 运行 → 得到 plot.png
3. 问题显现：画出的是**堆叠柱状图（Stacked Bar Plot）**，两大缺陷：①比较不同年份同一饮品销量不直观；②整体观感不佳、缺乏专业性

**引入反思——多模态模型的视觉推理**

1. 把 V1 代码 + plot.png 一起打包作为新输入
2. 提示多模态 LLM 扮演"专家数据分析师"做批判性评估
3. 多模态模型能"真正地看"这张图，分析可读性、清晰度、完整性，提出具体改进建议
4. 据反馈更新代码 → V2 code → 运行得到 plot_v2.png

## 模型分工

| 环节 | 角色 | 模型选择建议 |
|------|------|-------------|
| 初始生成 | 根据用户提示生成第一版代码 | GPT-4 / GPT-5 等强大通用模型 |
| 反思阶段 | 接收 V1 代码 + 图表 + 对话历史，扮演"专家分析师"给反馈并指导改进 | **具备强推理能力的"思考模型"（Reasoning Model）**更合适 |

反思提示语示例：

```
您是一位专业的数据分析师，能够为可视化提供建设性反馈。
{V1 代码} {plot.png} {对话历史记录}
步骤 1：评估所附图表的可读性、清晰度和完整性。
步骤 2：编写新代码来实现您的改进。
```

## 总结（原文）

- 反思机制**并非万能**，效果因场景而异——某些任务提升显著，另一些可能微乎其微
- 因此**了解反思对特定应用的影响至关重要**，它给出优化方向（调初始生成提示 or 调反思提示）

## 亮点与不足

- 亮点：展示了"反思"从纯文本扩展到多模态（用图像本身作为反馈信号）的关键一步，并给出可复制的提示词模板
- 不足：未量化 V1→V2 的评估结果（2.5 才补主观评估方案）；堆叠柱状图的选择本身更像初始提示词缺陷而非反思能挽救的问题
