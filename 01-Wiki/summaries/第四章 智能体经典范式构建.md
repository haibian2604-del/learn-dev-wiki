# 第四章 智能体经典范式构建

> hello-agents 第四章：从零实现三大经典智能体范式——ReAct、Plan-and-Solve、Reflection，并搭建基础组件（HelloAgentsLLM、ToolExecutor）。

## 核心观点

- **ReAct（Reasoning and Acting）**：由 Shunyu Yao 2022 年提出，Thought-Action-Observation 循环——思考指导行动，行动结果修正思考，重复直到 Finish（→ [[01-Wiki/concepts/ReAct]]）
- **Plan-and-Solve**：Lei Wang 2023 年提出，两阶段解耦——先规划（Planner 生成步骤列表）后执行（Executor 严格按计划逐步骤，带状态管理），适合结构性强可清晰分解的任务
- **Reflection**：赋予智能体"反思"能力，通过自我批判和修正优化结果
- **为什么从零实现**：成熟框架（LangChain/LlamaIndex）隐藏了机制；亲手处理输出解析、重试、死循环防护才能理解设计原理，从"使用者"变为"创造者"
- **工具三要素**：名称（唯一标识）+ 描述（**触发选择的关键，模型靠它决定何时用哪个工具**）+ 执行逻辑
- **ReAct 优势**：高可解释性（Thought 链透明）、动态规划纠错、工具协同
- **ReAct 局限**：强依赖 LLM 能力、多次调用效率低、提示词脆弱、可能陷入局部最优/原地打转（max_steps 安全阀）
- **调试技巧**：打印完整提示词、分析原始输出、验证工具输入输出、加 few-shot 示例、temperature=0

## 亮点与不足

- 亮点：三范式对比生动（侦探 vs 建筑师）；ReAct 从提示词模板→解析器（正则）→工具执行→历史整合的完整拆解；运行实例展示思考链条
- 亮点：工具描述的重要性强调（"模型靠 description 决定用哪个工具"，与 MCP/Skills 的 description 触发思想一致）
- 不足：Reflection 仅概述未展开实现；示例基于 SerpApi（需要外部 API key）
