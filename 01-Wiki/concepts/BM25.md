# BM25（Best Matching 25）

> 信息检索领域经过几十年验证的关键词检索/排序算法，是混合检索中 sparse 信号的核心来源。

## 定义
BM25 是基于概率检索模型的相关性打分函数：对查询词项在文档中的命中情况、词频饱和度与文档长度做归一化，输出稀疏检索得分。

## 机制/原理
- **精确术语匹配**：擅长短语/专有名词/精确编号（如"《消法》第二十四条""S1-Pro-Max""API 503"）。
- **稀有词高权重**：罕见词命中更有区分度。
- **文档长度归一化**：避免长文档因含更多词而占优。
- **关键参数**：k1（词频饱和，默认 1.5）、b（长度归一化，默认 0.75）。
- **中文支持**：LlamaIndex 的 BM25Retriever 内部用 jieba 分词；专业领域可自定义词典提升效果。

## 例子
```python
bm25_retriever = BM25Retriever.from_defaults(
    nodes=nodes, similarity_top_k=10, k1=1.5, b=0.75, verbose=True,
)
```

## 边界与常见误区
- BM25 只做字面匹配，对同义词/语义等价（"退钱" vs "退款"）无能为力——这是与向量检索互补的根本原因。
- 在混合检索中需与向量分数融合（见 [[01-Wiki/concepts/混合检索]] 的 RRF）。
- 百万级节点时 BM25 倒排索引内存开销大，可考虑外包给 Elasticsearch。
