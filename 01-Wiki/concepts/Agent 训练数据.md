# Agent 训练数据

## 核心原则

**模型会变成它吃的数据的形状。** 只用 Agent 轨迹训练 → 能力偏移（catastrophic forgetting 的 Agent 语境说法）：所有问题都想调工具、格式过度结构化、拒绝回答通用问题、长文本退化、安全对齐退化。

## 六类数据

| 类别 | 作用 | 配比（SFT） |
|---|---|---|
| Agent 轨迹 | 多轮推理+工具调用 | 35-45%（≤50% 硬线） |
| Tool Calling 单轮 | function calling 基本功 | 10-15% |
| 通用指令跟随 | 防能力偏移压舱石 | 15-20%（≥15% 最低线） |
| 长文本理解 | 保持长上下文（Agent 天然 4K-8K） | 5-10% |
| 安全/拒绝 | Agent 能执行操作，比对话更需安全 | 5-10%（≥5% 底线） |
| 代码/推理 | 保持思维链质量 | 10-15% |

关键细节：通用指令数据**不能出现工具调用**（模型要学"不是所有问题都要调工具"）；安全数据必须含 Prompt 注入样本（工具返回中嵌恶意指令）。

## 模型规模差异

越小越易被带偏需更大通用比例：1B-3B（轨迹 25-35%/通用 30-40%）→ 7B-13B（35-45%/20-25%）→ 30B-70B（40-50%/15-20%）→ 70B+（45-55%/10-15%）。**宁可 Agent 弱一点不能通用能力崩**。

## RL 阶段考量

任务分布 30% 简单 + 50% 中等 + 20% 困难；RL 任务覆盖所有工具类型（没训到的工具会退化）；RL 也致通用退化 → RL loss 混少量 SFT loss 或定期 benchmark 检查暂停补救。

## 质量 > 数量

三维度：正确性（工具参数错但碰巧对/冗余调用/Think 与行为不一致/没用工具返回）、多样性（工具/难度/长度/错误恢复/拒绝覆盖）、格式一致性（统一 JSON schema、think 标签统一、角色标记统一）。

数据量经验：入门 ~10K（轨迹 1-5K）/ 生产 50-100K（轨迹 10-50K）/ 大规模 200K+。**1 万高质量胜过 10 万低质量**。

## 调试与飞轮

监控：Agent 完成率（每 500 步）、通用 benchmark（检测偏移）、工具格式正确率、不该调工具时调用率、安全拒绝率、长文本准确率。A/B 测试判定配比：**Agent 能力显著提升 + 通用退化 ≤5%**（>10% 需调整）。

**数据飞轮**：线上日志（脱敏）→ 自动筛选（成功轨迹直入/失败轨迹分析归因/边界案例人工标注）→ 重训上线。线上数据分布与手工构造不同，是最宝贵的数据源；前提是脱敏与合规审查。
