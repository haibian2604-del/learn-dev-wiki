# AutoGen（Microsoft）

## 是什么

微软开源的 AI Agent 框架，支持完全自主或人类协同的多 Agent 系统，强调 Agent 之间的对话与协作。

## 关键事实

- **GitHub Stars**：43.1k+（Python/.NET）
- **核心能力**：多 Agent 对话协作；内置 AutoGen Studio 可视化界面；原生支持 Playwright 网页自动化
- **企业级定位**：微软官方支持、稳定性强，适合复杂工作流编排
- **支持模型**：OpenAI、Azure OpenAI、Anthropic、Ollama、Gemini
- **选型定位**：企业级多 Agent 协作、客服等对话式 AI 应用（→ [[01-Wiki/summaries/2026 年 AI Agent 技术全景]]）
