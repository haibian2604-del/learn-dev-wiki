# CrewAI

## 是什么

专注多 Agent 协作的 Python 框架，提供强大的 Agent 角色定义与任务分配机制；完全独立，不依赖 LangChain。

## 关键事实

- **GitHub Stars**：30k+
- **双模式**：Crews（团队协作）+ Flows（事件驱动）
- **设计**：高层级简单性（上手快 ⭐⭐）+ 底层精细化控制
- **适用场景**：快速搭建团队（多 Agent 协作）、高度定制化自主 Agent；研究实验场景（MetaGPT > CrewAI > LangGraph）
- **选型定位**：快速验证与团队式多 Agent 协作（→ [[01-Wiki/summaries/2026 年 AI Agent 技术全景]]）
